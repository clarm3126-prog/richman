# 탭 안내 글 초안

`python scripts/make_tab_guides.py` 로 다시 만듭니다.
숫자는 만든 시점의 data/*.json 값입니다.

## 미너비니 탭

```
미너비니 탭 보는 법입니다.

추세가 이미 만들어진 종목만 모읍니다.

오늘 734개를 계산해서 34개가 걸렸습니다.

조건은 9개입니다.
초록은 통과, 회색은 못 넘은 겁니다.

· 이동평균선 위에 있나
· 순서대로 정렬됐나
· 고점 근처인가
· 시장보다 강한가

숫자를 읽는 것보다 회색 칸을 보는 게
빠릅니다.

검증은 평균 -6.77%였습니다.
같은 기간 코스피는 -11.1%였고요.

좋게 나오지 않았습니다.
그래서 손절선이 붙어 있는 겁니다.

종목 추천이 아닙니다.
조건에 걸렸는지만 계산합니다.

댓글에 '노트'라고 남겨주세요.
링크 디엠으로 보내드릴게요.
```

## 손절선

```

받습니다.

대입해봤습니다.

-7%로 자르면 평균 -6.77%, 승률
13.7%입니다.

아예 안 걸면 평균 -13.49%, 승률
27.1%고요.

승률은 안 거는 쪽이 높습니다.

-60.9%였습니다.
```
